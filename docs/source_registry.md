# Source Registry

A source cannot be activated in production until its access method and usage conditions are documented.

## Approved Integrations
- **Gemini**: Intent extraction and product classification.
- **Geoapify**: Geocoding and reverse geocoding.
- **Nimbleway**: Web search and supplier discovery.
- **Apify**: Controlled extraction and website crawling.
- **Supabase**: Primary database and system of record.
- **Government Open Data**: (e.g., data.gov.in, MCA)
